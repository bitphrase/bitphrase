# data/en/ — исходные данные английских словарей

[English](README.md) · **Русский**

Всё здесь нужно только на этапе **сборки** английских словарей. Во время работы приложение
использует лишь замороженные списки слов в `src/lang/en/dict.json`; грамматика, которая
складывает из них предложения, — `src/lang/en/grammar.ts`. Русские данные — уровнем выше, в [data/](../README.ru.md).

В git только `seed/` и это описание; остальное скачивается или генерируется:

```sh
tools/data/en/fetch_raw.sh     # один раз: ~0,6 ГБ в data/en/raw/
tools/data/en/build_all.sh     # ~4 минуты: lexicon/, candidates/, dicts/, src/lang/en/dict.json
```

Хватает обычного `python3` (без пакетов).

## Производные таблицы

Все TSV — UTF-8, разделитель TAB, без кавычек.

### lexicon/
- `wikt.jsonl.gz` (`extract_wiktionary.py`) — компактная выборка Викисловаря: однословные
  существительные, глаголы, прилагательные и имена собственные; формы (мн. ч.; -s, -ing,
  прошедшее, причастие прошедшего; сравнительная степень) без устаревших и диалектных
  вариантов; пометы значений, категории имён и мест, первое толкование.
- `wordnet.tsv`, `wordnet_exc.tsv` (`extract_wordnet.py`) — по (лемма, часть речи): число
  значений, частота в размеченном корпусе, класс каждого значения, глагольные рамки первого
  и всех значений (8 = «Somebody ----s something», 9 = «... somebody»), цепочки гиперонимов;
  неправильные формы.
- `an.json` — слово → начинается ли с гласного звука (CMUdict).

### candidates/ (`build_candidates.py`) — всё, по убыванию частоты, с `auto_flags`

`noun.tsv`, `verb.tsv`, `adj.tsv`: формы, частота (субтитры, на миллион), конкретность,
преобладающая часть речи (`dom_pos`), класс WordNet, «a/an», первое толкование.

| флаг | смысл |
|---|---|
| offensive | vulgar / offensive / derogatory / slur / ethnic / pejorative / euphemistic хотя бы в одном значении |
| archaic, informal | все значения устар./редк./истор. или жарг./разг./диал. |
| non_us | все значения только британские/австралийские... (варианты написания вроде «colour») |
| form_of_only | только значения «форма слова» / сокращение |
| not_plain, too_short | не только строчные латинские буквы; короче 3 букв |
| not_in_wordnet, no_pronunciation | нет в WordNet; нет в CMUdict (не выбрать «a» или «an») |
| no_plural, plural_same, mostly_uncountable, plural_only | сущ.: нет мн. ч., sheep/sheep, неисчисляемые, scissors |
| homonym_proper | существительное — ещё и имя собственное (lee, vega) — для людей и животных исключается |
| forms_missing, forms_coincide, past_variants, irregular_s | глаголы: нет формы; две формы совпадают (put/put — время по слову не понять); dreamed/dreamt |
| predicative_only, comparative, participle_like, also_noun_or_verb | прилагательные |

`name.tsv` — имена SSA с 1940 года: пол, доля и флаги `unisex` (10–90 %), `homonym_common`
(Rose, Bill), `not_in_wiktionary`. `surname.tsv` — фамилии переписи (топ-30 000) с
`homonym_common` (Brown, Young) и `homonym_name` (Thomas). `place.tsv` — страны и города
от 300 000 жителей с однословным ASCII-названием.

### dicts/ — что отобрал `gen_dicts.py` (для просмотра)

По слову в строке, в порядке словаря (раньше — частотнее).

## Как отбираются словари (`tools/data/en/gen_dicts.py`)

- **Каждая словоформа — только в одном словаре**, включая притяжательные (Anna's → annas).
  Сначала служебные слова (определители, предлоги, модальные, is/are/was/were), обращения,
  глаголы вида «likes painting», глаголы, затем имена, фамилии, места, люди и животные,
  предметы, прилагательные. Уже занятая форма пропускается — так разбор однозначен.
- **Глаголы** — группы по тому, что идёт дальше (`seed/verb_groups.tsv`): предмет, человек,
  «to кому-то», «with…», «about…», движение, место. В группу «what» добавляются частые
  глаголы, у которых первое значение WordNet берёт «something», а преобладающая часть речи —
  глагол. Все четыре формы должны различаться.
- **Предметы** — первое значение в noun.artifact/food/plant/object/body, конкретность ≥ 3,5,
  исчисляемые, с мн. ч. **Люди** — noun.person: профессии по гиперониму (worker,
  professional, artist...), остальные — роли (guest, passenger); отрицательные, религиозные,
  национальные и политические значения исключены. **Животные** — noun.animal с «animal»
  среди гиперонимов.
- **Прилагательные** — преобладающая часть речи «Adjective», конкретные — первыми.
- **Имена** — самые популярные с 1940 года, не унисекс. **Фамилии** — верх рейтинга переписи,
  не совпадающие с обычными словами. **Места** — страны и известные города; омоним (Nice,
  Reading) — только если это страна (China, Turkey).
- `seed/stoplist.tsv` — слова, убранные вручную (интимная анатомия, оружие, наркотики,
  религия, насилие).

Сейчас: прилагательных 3911, имён 2048, фамилий 8192, обращений 42, профессий 479,
ролей 478, животных 115, предметов 2271, мест 296, глаголов 1315. Это 27 486 шаблонов и
ёмкость на 8 байт в 7 словах (83 бита; нужно не меньше 80).
