# data/ — исходные данные для словарей bitphrase

[English](README.md) · **Русский**

Здесь лежат исходные данные **русских** словарей. Данные и документация английских
словарей — в `data/en/` (см. [data/en/README.ru.md](en/README.ru.md)).

Всё здесь нужно только на этапе **сборки** словарей. В рантайм попадут лишь итоговые
замороженные списки слов с формами — словарь приложения `src/lang/ru/dict.json`, который
читает кодек (`src/core/engine.ts` + `src/lang/ru/grammar.ts`).

Пересборка всего производного (кроме `raw/`): `tools/data/build_all.sh`.

## Производные таблицы

Все TSV — UTF-8, разделитель TAB, без кавычек. Варианты формы через `/`
(первый — основной). Ударение — U+0301 (сравнивать после удаления).

### morph/ — полные парадигмы и их сверка
- `oc_{noun,adj,verb}.tsv` — все лексемы OpenCorpora, чья лемма есть в НКРЯ
  (21 528 сущ., 10 590 прил., 12 513 глаг.). Омонимы — отдельными строками
  (лев-зверь / Лев-имя / лев-валюта). Колонки ячеек: `sing:nomn … plur:loct`,
  `gen2/loc2/voct`; у прилагательных `masc|neut|femn|plur × падеж`, В.п.
  `:anim/:inan`, краткие формы, сравн. степень; у глаголов инфинитив, наст./буд.
  время по лицам, прошедшее, повелительное, деепричастия, причастия.
  Пометы OpenCorpora (`oc_grammemes`): anim/inan, род, Fixd (несклоняемое),
  Pltm/Sgtm, ms-f (общий род), Name/Surn/Geox (имена), Infr/Slng/Arch/Obsc, perf/impf, tran/intr…
- `oc_name.tsv` (личные имена, помета Name, 1 556 лексем) и `oc_place.tsv` (топонимы,
  Geox, 1 282) — **два отдельных словаря, не смешиваются** ни между собой, ни с `oc_noun`.
  Фамилии/отчества/организации не берутся. Критерий: лемма есть среди имён собственных
  НКРЯ, или в en-Викисловаре в категориях своего вида (имена / города, страны, реки...),
  или И.п. встречается в субтитрах ≥ 30 раз (здесь `subs_forms_count` = частота только И.п.).
- `oc_missing_from_rnc.tsv` — леммы НКРЯ без лексемы в OpenCorpora (в основном превосходные степени и субстантиваты).
- `wikt_{noun,adj,verb,prop}.tsv` — те же колонки (`prop` — имена и топонимы одним файлом,
  как в источнике: Викисловарь их не разделяет; разносятся по name/place при сверке) по Викисловарю (`source` = ru|en), с ударениями и типом по Зализняку (`wikt_class`).
- `verified_{noun,adj,verb}.tsv` — **эталон**: парадигма OpenCorpora, сверенная с Викисловарём.
  Ячейка `слоно́м` — подтверждена (с ударением); `?форма` — только OpenCorpora;
  `!oc|wikt` — расхождение. `core_ok=1` — подтверждены все ячейки, нужные шаблону
  (сущ.: И/Р/В/Т ед., И/Р мн.; прил.: все падежи; глаг.: инф., 3 л. ед./мн.).
  Подтверждено: сущ. 21 152 / 21 528, прил. 9 710 / 10 590, глаг. 12 389 / 12 513,
  имена 614 / 1 556, топонимы 934 / 1 282 (у остальных в основном нет статьи в
  Викисловаре — это иностранные имена из субтитров и малые топонимы).
- `crosscheck_conflicts_{pos}.tsv` — все расхождения для ручного разбора
  (чаще всего — одушевлённость в В.п., варианты «стелит/стелет», ё/е).

### Фамилии — отдельный словарь (`tools/data/build_surnames.py`)
- `morph/oc_surname.tsv` — топ-20 000 фамилий по распространённости; для 5 857 есть лексема
  OpenCorpora: формы `masc|femn|plur × падеж` (ё восстановлена: Семёнов, Фёдоров). `type`:
  `ov_in` (-ов/-ев/-ин/-ын), `adj` (-ский/-ой/-ый), `cons` (на согласную), `other` (несклоняемые).
  `rule_ok` — совпадение с правилами склонения фамилий (прототип TS-кода): ov_in 5 043 / 5 078,
  adj 337 / 339, cons 418 / 423. Расхождения — фамилии, которые OpenCorpora склоняет как
  иностранные (Синицин, Зайкин: «-ом», женская несклоняемая) — исключаются.
- `candidates/surname.tsv` — `display`, `rank`, `type`, формы м./ж. И/Р/В/Т, `auto_flags`:

| флаг | смысл |
|---|---|
| rule_mismatch | OpenCorpora расходится с правилами (жёсткий) |
| indeclinable, femn_indeclinable | Белых, Шевченко; Шевчук/Ким (женская форма без падежей) — жёсткий |
| famous_person | часто в текстах НКРЯ при скромной распространённости: Пушкин, Брежнев — жёсткий |
| homonym_common | совпадает с сущ./прил.: Мороз, Жук, Калашников, Белый — жёсткий |
| homonym_name, homonym_place | Королёв, Михайлов — мягкий (слоты разные, путаницы для декодера нет) |
| not_in_opencorpora / forms_by_rule | нет в OpenCorpora, формы по проверенным правилам (ov_in, adj) |
| oc_incomplete | в OpenCorpora нет женских форм (Кротов) — берутся по правилам |

  Чистых (без жёстких флагов): в топ-1000 — 913, топ-2048 — 1 836, топ-4096 — 3 591, топ-8192 — 6 975.

### Профессии, бренды, отчества — отдельные словари
- `candidates/profession.tsv` (`build_professions.py`) — одушевлённые сущ., у которых значение
  в RuWordNet лежит под РАБОТНИК / ЧЕЛОВЕК ПО СФЕРЕ ДЕЯТЕЛЬНОСТИ / ВОЕННОСЛУЖАЩИЙ /
  СПЕЦИАЛИСТ / РУКОВОДИТЕЛЬ … (`kind=work`) или ЧЕЛОВЕК ПО РОЛИ (`role`: пассажир, гость).
  Формы — из проверенных парадигм сущ. Флаги: `negative_sense` (все значения —
  преступник/ничтожество; жёсткий), `some_negative_sense`, `has_non_person_sense`
  (папа, модель), `sensitive` (религия, политика, монархи: президент, патриарх, фюрер).
  Годных (ipm ≥ 1, без sensitive): 705 (м.р. 608, ж.р. 97).
- `candidates/brand.tsv` (`build_brands.py`) — `source=seed`: ручной список
  `data/seed/brands_seed.tsv` (147 брендов кириллицей: Тойота, Самсунг, Айфон, Сникерс…;
  в Wikidata они обычно латиницей); `source=wikidata` — 690+ кандидатов с флагом
  `not_curated` (много мусора: Геринг, Шорт, Ново — только ручной разбор). Склонение:
  OpenCorpora или правила (`forms_by_rule`), `suspicious_oc_form` — ошибки OC
  (Дайсном, Опель ж.р.). Флаги `homonym_*` у брендов мягкие (мерседес, ксерокс — сами стали
  нарицательными), но такие слова не должны попасть одновременно в словарь сущ.;
  `sensitive` — алкоголь, табак, госкомпании, соцсети. Из затравки годных по форме 141,
  склоняемых 102.
- `candidates/patronymic.tsv` (`build_patronymics.py`) — лексемы OpenCorpora Patr; берётся
  привычный вариант (Михайлович, а не книжное «Михаилович»), женская форма по правилу
  (Ивановна), `base_name` — имя-основа. Проверка падежей правилами; -ич (Ильич → Ильинична,
  Фомич, Кузьмич) — исключения. Популярных и чистых: 60; от «чистых» имён: 193.

### lexicon/ — семантика и тезаурус
- `wikt_ru_subset.jsonl.gz`, `wikt_en_subset.jsonl.gz` — компактные выборки Викисловарей по леммам-кандидатам.
- `ruwordnet_senses.tsv` — значения однословных лемм: синсет, толкование, синонимы,
  цепочка гиперонимов, класс WordNet (`noun.animal`, `noun.artifact`, `verb.contact`…),
  английские леммы и их конкретность (Brysbaert).
- `conflict_pairs_{pos}.tsv` — пары, которые нельзя держать в одном словаре:
  `synonym:*` (RuWordNet / ru- / en-Викисловарь), `hypernym:ruwikt`,
  `edit1` (отличаются одной буквой), `dim` (уменьшительное),
  для имён `hypocorism` (Мария — Маша — Маня); есть и `conflict_pairs_surname.tsv`.

### candidates/ — сводные таблицы для отбора (по убыванию частоты)
`{noun,adj,verb}.tsv`: частоты (НКРЯ ipm, range, субтитры), формы с ударением,
морфологические признаки, семантический класс, конкретность, синонимы, метаграммы,
переводы, толкование и `auto_flags` — причины автоматического исключения:

| флаг | смысл |
|---|---|
| proper, abbr | имя собственное / аббревиатура |
| obscene_or_pejorative | обсц./бран./груб. (ru), vulgar/derogatory (en), Obsc (OC) — хотя бы в одном значении |
| archaic, informal | все значения устар./истор. или разг./жарг./прост./рег. |
| diminutive_or_aug | уменьшительное/увеличительное от другого слова (`dim_of`) |
| pluralia_tantum, common_gender, substantivized_adj | ножницы; сирота; столовая |
| ablt_cluster | Т.п. начинается со стечения согласных (льдом, львом) — проверить «подо/надо» |
| possessive, pronominal_or_numeral, ne_prefix, participle_like, nonstandard_lemma | для прилагательных |
| not_imperfective, intransitive, reflexive, impersonal | для глаголов |
| forms_unverified | ядровые формы не подтверждены вторым источником |
| not_plain_cyrillic | дефис, пробел и т.п. |

`name.tsv` (личные имена) и `place.tsv` (топонимы) — два отдельных словаря.
Общее: `display` (с заглавной), род, формы, частоты. Только в `name.tsv`: `name_form`
(full/short), `name_origin`, `hypocorisms`; только в `place.tsv`: `place_type` (city,
capital, country, river, lake, sea, mountain, island, region...), `where` (страна города). Флаги:

| флаг | смысл |
|---|---|
| unisex_name | Саша, Женя — род неоднозначен |
| not_russian_given_name | нет в «Russian given names» (Том, Джейн из субтитров) |
| homonym_common | совпадает с нарицательным (Роза, Вера, Лев, Орёл) |
| homonym_name_place | слово есть в обоих словарях: Лена (имя и река), Юра |
| indeclinable, pluralia_tantum | Сочи, Осло; Афины, Альпы |
| toponym_ov_in | Пушкин, Александров (Т.п. -ом, омонимия с фамилиями) |
| place_type_unknown | нет категории места в Викисловаре |
| country_or_region | мягкий: страна/регион — проверить на политическую окраску |

После жёстких флагов: ~400 имён (~270 частых) и ~680 топонимов (~290 частых).

Размер пула после жёстких флагов (длина 3–10, ipm ≥ 1): ~5 800 конкретных
существительных (из них ~1 550 одушевлённых), ~3 500 прилагательных,
~1 400 переходных глаголов НСВ (~680 «физических» по WordNet). До ручной чистки.

### exceptions/ — где правила не работают
- `adj_rule_mismatches.tsv` — прогон правил склонения прилагательных (сейчас — в
  `src/lang/ru/morph.ts`) по всем прилагательным: 10 400 из 10 472 совпали полностью;
  все расхождения — притяжательные (божий, лисий…) и 1–2 мусорные леммы.

## Как пересобрать
```sh
python3 -m venv .venv
.venv/bin/pip install --no-index --find-links data/raw/opencorpora_pymorphy3 pymorphy3 pymorphy3-dicts-ru
tools/data/build_all.sh            # ~3 минуты
```
